隱私權政策

最後更新：2026 年 10 月 22 日

「說書人」是作者個人自用的桌面工具，唯一的用途是透過 YouTube Data API 將作者自製的影片上傳到作者本人的 YouTube 頻道。

資料的使用

  • 本工具只存取作者本人的 YouTube 帳戶，用來上傳影片、設定標題、說明與發布時間，以及查詢上傳後的處理狀態。
  • 本工具不蒐集、不儲存、不分享任何其他使用者的個人資料。
  • Google 授權憑證只保存在作者自己的電腦上（Windows 認證管理員），不會傳送到任何第三方伺服器。

Google API 服務

本工具對 Google API 取得之資訊的使用，遵守 Google API 服務使用者資料政策，包括「有限使用」的規定。
